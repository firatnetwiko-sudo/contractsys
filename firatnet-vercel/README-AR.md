# نظام فرات نت على Vercel (مقفل بحسابات حقيقية)

## الخطوات
1. ارفع هذا المجلد كاملاً إلى مستودع GitHub جديد (أو استخدم `vercel` من الطرفية داخل المجلد).
2. في Vercel: New Project ← اختر المستودع ← Deploy (لا يحتاج Build).
3. أنشئ قاعدة البيانات: مشروعك ← Storage ← Marketplace ← **Upstash Redis** ← الخطة المجانية ← Connect Project. تُضاف تلقائياً `KV_REST_API_URL` و `KV_REST_API_TOKEN`.
4. Settings ← Environment Variables أضف:
   - `ADMIN_USER` = اسم المدير
   - `ADMIN_PASSWORD` = كلمة مرور قوية (6 أحرف فأكثر)
   - `SESSION_SECRET` = أي نص عشوائي طويل
5. اعمل Redeploy.
6. افتح الرابط وادخل بـ ADMIN_USER / ADMIN_PASSWORD (يُنشأ حساب المدير أول دخول)، ثم أنشئ بقية المستخدمين من قسم «المستخدمون».

## القفل
- لا توجد شاشة إنشاء حساب. الدخول فقط بأسماء موجودة في قاعدة البيانات.
- كلمات المرور مشفّرة (scrypt) على الخادم، والجلسة كوكي HttpOnly موقّع.
- الصلاحيات (عرض/إنشاء/تعديل/حذف) تُفرض على الخادم نفسه.
- محاولات الدخول الخاطئة محدودة (10 كل 5 دقائق لكل عنوان).
- بعد أول تشغيل يمكنك حذف ADMIN_PASSWORD (لا يُستخدم إلا إذا فرغت قائمة المستخدمين).

## ملاحظات
- فواتيرك وعقودك المحفوظة سابقاً في متصفحك على نفس النطاق تُنقل تلقائياً إلى الخادم عند أول دخول للمدير.
- أقصى حجم للمرفق 10 ميغابايت (PDF أو صورة).
